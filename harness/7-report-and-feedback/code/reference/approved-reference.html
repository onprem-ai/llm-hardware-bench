08 · Method

Measurement design and topology

AIPerf → HAProxy (leastconn) ├─ GLM replica A → GPUs 0–3 · TP4 └─ GLM replica B → GPUs 4–7 · TP4

Each operating point has three repetitions, same-shape warm-up, a 15-second settling interval, deterministic sampling, streaming output, and closed-loop concurrency. Measured requests are max(32, 4× concurrency).
