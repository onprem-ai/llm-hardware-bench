Limitations and provenance
Interpretation
  • Results apply to this model revision, runtime, topology, and host.
  • Prefill and Decode are selected independently by maximum useful throughput.
  • Internal request-mix labels are not shown.
  • GPU board energy is not whole-server wall energy.
  • Frozen before measurement: Dell xe7740 deployment parameters verbatim by user decision (param raster skipped); corrected-cold aiperf invocation; xe7740 published 8-point axis [1,32,64,96,128,160,192,224].
  • Deployment-level profile splice (two fleet launches): decode-optimized (max_running_requests 48, max_prefill_tokens 32768, chunked_prefill 4096, mamba cache 240, cuda graph 48, NEXTN 3/1/4, radix on) and prefill-optimized-uncached (24/65536/16384, mamba 120, graph 24, no speculative, --disable-radix-cache).
  • Engine image: lmsysorg/sglang base pinned by OCI digest with the SM120 guard re-derived by inspection (qwen_sparse_attn_backend.py: TRT-LLM QSA decode path, SM100-only -> SM100-or-SM120; the single documented edit in local/qwen38-flash-next-sm120:comino-patched, matching the xe7740 operator-patch description).
  • Prefill verified uncached on every rep: --disable-radix-cache by launch flag plus client-side usage_prompt_cache_read_tokens == 0 (aiperf export); decode runs radix-on by design (ISL 8).
  • Correctness gate 7/7 through the measured path after each fleet boot; B0 unloaded idle and B1-pre/post loaded-idle baselines captured.
  • 48 measured runs, 0 aiperf errors, 0 gate violations, 0 excluded runs.
