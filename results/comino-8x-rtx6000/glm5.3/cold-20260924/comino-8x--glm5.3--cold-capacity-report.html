Limitations and provenance
Interpretation
  • Results apply to this model revision, runtime, topology, and host.
  • Prefill and Decode are selected independently by maximum useful throughput.
  • Internal request-mix labels are not shown.
  • GPU board energy is not whole-server wall energy.
  • Frozen before measurement: Dell xe7740 deployment parameters verbatim by user decision (param raster skipped); corrected-cold aiperf invocation (num-dataset-entries 4000, sequential, per-(C,rep) seeds 600000+C*1000+rep); published 7-point axis [1,8,16,24,32,48,64].
  • Decode profile spliced like the published xe7740 series: C1-C24 on max_num_seqs 32 / cudagraph 128, C32-C64 on max_num_seqs 64 / cudagraph 256 (two container launches).
  • Engine: vLLM 0.26.1rc0 (voipmonitor/vllm base), InstantTensor load, modelopt_fp4, KV fp8, MTP-3, B12X MLA sparse, async scheduling; realized args verified from startup logs (segments/*/params.txt).
  • Prefill verified uncached on every rep: engine /metrics prefix_cache_hits/queries deltas, fail-closed gate <=1%, all reps 0.0%; client-side usage_prompt_cache_read_tokens 0.
  • Correctness gate 7/7 through the measured path after each fleet boot; B0 unloaded idle and B1-pre/post loaded-idle baselines captured (preflight/ + baselines/).
  • 42 measured runs, 0 aiperf errors, 0 gate violations, 0 excluded runs.
