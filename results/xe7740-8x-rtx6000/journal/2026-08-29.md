## Extended PCIe/DCGM telemetry

Implemented reusable DCGM discovery, metric-availability validation, static
PCIe topology capture, run-boundary link snapshots, exact-window
VictoriaMetrics export, and fabric summarization.

The implementation was synchronized to the host but deliberately not activated.
The active Qwen3.8 campaign must finish and be finalized before exporter changes
or active P2P/NCCL validation.

Observed current telemetry reference:

```text
container: obs-dcgm-exporter
image tag: nvcr.io/nvidia/k8s/dcgm-exporter:4.8.3
image digest: sha256:613ab03c11d442fd960ff515f547e9921537454a712d08160bc8f677f89f1c35
```

The exporter image did not expose `dcgmi`, so formal per-GPU profile-group
discovery requires a matching utility container or host package in the idle
window.

A read-only query of existing VictoriaMetrics history found eight per-GPU series
for PCIe RX/TX and replay counters. Some requested profiling series, including
SM active and SM occupancy, were absent. This observation is not yet a formal
support classification; controlled-load validation remains open.
