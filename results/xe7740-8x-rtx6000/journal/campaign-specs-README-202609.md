# Campaign pointers

These YAML files are compact pointers to external campaign artifacts. They do
not make the repository copy authoritative for results.

Rules:

- Do not move an active or legacy campaign merely to satisfy the canonical path.
- Populate hashes and revisions only from authoritative artifacts.
- Update status only after verifying the external campaign state.
- Never include raw request or telemetry data here.
- New campaigns should use the canonical external hierarchy in
  `harness/5-formal-campaign/RULES.md`.
